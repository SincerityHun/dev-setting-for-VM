# dev-setting-for-VM

VM development environment setup scripts.

## Usage

### Neovim

- Install Neovim and copy the bundled config:

- `make neovim`

### tmux

- Create `~/.tmux.conf`:

- `make tmux-conf`

### Node.js

- Install the latest Current Node.js with nvm:

- `make node`

- Install a specific Node.js version with nvm:

- `make node VERSION=22.11.0`
